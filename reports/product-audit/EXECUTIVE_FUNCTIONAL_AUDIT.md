# Executive functional audit

E13BD serves internal operators who run and govern database audits, inspect results and distribute reports. Its core capability is strong, but the automation workspace favors configuration over daily operational awareness. The highest-value change is not more control: it is an operational home that makes attention, next work and recovery obvious.

## Top five improvements

1. Default Automation to operational overview.
2. Surface next scheduled, running, failed and recent results from existing data.
3. Link failed history to contextual retry eligibility and explanation.
4. Move/collapse recipient, routing, mapping and advanced scheduler configuration.
5. Establish action hierarchy: Run Now primary; edit secondary; delete guarded.

Product tests prove safety, not task clarity. Future Dev Agent capability: FunctionalProductAuditor based on a running UI, journeys and capability inventory.
