# E13BD external acceptance lessons

E13BD is a brownfield acceptance scenario: FastAPI/pytest plus React/Vite/Vitest/Playwright, SQLite artifacts, optional Oracle, pip/npm, lint and report-generation workloads.

The reusable fixture contract is abstract: local versus cloud-synced source/tool provenance; an expected-expensive PDF/ZIP test; generated SQLite/PDF/ZIP residue; secret-shaped exception sanitization; and unified lint/test/build/E2E receipts. It must prove that VERIFY_ONLY cannot modify product bytes and that missing or stale evidence fails certification.
