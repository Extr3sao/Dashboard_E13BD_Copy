# Core journeys

1. **Status → action:** Automation currently opens Jobs; operator must scan configuration before seeing attention/running/next work.
2. **Run now:** Jobs → configured job → `EXECUTA ARA`; discoverable, but adjacent to edit/activate/delete and detailed configuration.
3. **Failure → recovery:** History/Retry are separate panels; recovery context is not co-located with execution result.
4. **Schema audit:** choose profile/schema → start audit → inspect/generate report; clear main action, but requires database readiness.
